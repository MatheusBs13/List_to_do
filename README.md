# ✅ List To Do

Lista de tarefas simples feita com **HTML, CSS e JavaScript puro**, sem frameworks nem bibliotecas além do Font Awesome para os ícones.

## 📒 Funcionalidades

- Adicionar tarefas pelo botão **+** ou pressionando **Enter**
- Editar o nome de uma tarefa por uma janela de edição (modal)
- Excluir tarefas, com confirmação antes de apagar
- Interface escura e centralizada, com ícones de editar e excluir em cada item

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript (manipulação do DOM)
- [Font Awesome 4.7](https://fontawesome.com/v4/) (via CDN)

## ▶️ Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/MatheusBs13/List_to_do.git
   ```
2. Abra o arquivo `To-do_list/To-Do-List/Index.html` no navegador.

Não precisa de instalação nem de servidor.
